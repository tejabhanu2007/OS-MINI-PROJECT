# CampusCompute

Modular C implementation of the OS mini-project. The executable name and commands are intentionally retained for existing terminal screenshots and tests.

Build with `make`; verify the scheduling output with `make test`.

Commands: `help`, `fcfs jobs.csv`, `rr 2 jobs.csv`, `priority jobs.csv`, `compare jobs.csv`, `logger N`, `ipc`, `banker safe|unsafe`, `worker normal|fail`, `limit`, `cleanup`, and `all`.
